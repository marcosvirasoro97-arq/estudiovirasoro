# Estudio Virasoro Arquitectos

Sitio web estático: `index.html` + carpeta `images/`. No necesita instalar nada.

## Publicar con GitHub Pages
1. En github.com crear un repositorio nuevo (por ejemplo `estudiovirasoro`), público.
2. Subir TODO el contenido de esta carpeta (index.html, robots.txt, README.md y la carpeta images), con "Add file > Upload files".
3. Ir a Settings > Pages. En "Source" elegir "Deploy from a branch", rama `main`, carpeta `/ (root)`, y Save.
4. En un par de minutos queda online en https://TU-USUARIO.github.io/estudiovirasoro/

## Dominio propio (ej. estudiovirasoro.com.ar)
1. Registrar el dominio en NIC Argentina.
2. En Settings > Pages > Custom domain, escribir el dominio.
3. En la zona DNS del dominio, crear los registros que indica GitHub (A hacia las IP de GitHub Pages y un CNAME para www).
4. Activar "Enforce HTTPS".

## Para Google
- Agregar el sitio en Google Search Console y pedir la indexación.
- Crear el Perfil de Empresa de Google con la dirección del km 56,5 de la Panamericana.
